# Aritan Especialista — Landing Page

Página de vendas pessoal do Aritan (mercado imobiliário, Niterói e RJ).
Captação de leads para financiamento da casa própria (MCMV / SBPE), com simulador,
formulário com verificação de telefone e WhatsApp.

## Arquivos
- `index.html` — página principal
- `politica-de-privacidade.html` — política de privacidade (LGPD)
- `img/` — foto do Aritan e fotos dos depoimentos

## Publicar
Dois cliques em `PUBLICAR-ARITAN.command` (commit + push para este repo).
